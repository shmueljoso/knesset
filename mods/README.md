# מודים – "כנסת אמיתית"

המשחק מגיע עם עולם בדיוני. כדי לשחק עם הרכב כנסת אחר (למשל הרכב אמיתי), יוצרים קובץ JSON לפי `TEMPLATE.real-knesset.json` וטוענים אותו במסך יצירת הדמות → שלב "מפלגה" → "טעינת כנסת מקובץ".

הריפו לא כולל נתונים על פוליטיקאים אמיתיים – את הקובץ ממלא השחקן.

| שדה | חובה | הסבר |
|---|---|---|
| `name` | ✔ | שם ההרכב |
| `coalition` | | מזהי המפלגות בקואליציה הפותחת (אחרת – מחושבת אוטומטית) |
| `parties[].id` | ✔ | מזהה באותיות לטיניות |
| `parties[].name` / `short` | ✔ / | שם מלא ומקוצר |
| `parties[].color` | ✔ | `#RRGGBB` |
| `parties[].ideology` | ✔ | `econ` (−רווחה / +שוק), `security` (−יוני / +ניצי), `religion` (−חילוני / +דתי), `judiciary` (−בית משפט חזק / +ריבונות הכנסת), כל אחד בין −100 ל-100 |
| `parties[].seats` | ✔ | מושבים; הסכום חייב להיות 120 |
| `parties[].primaries` | | `true` אם הרשימה נבחרת בפריימריז |
| `parties[].sectors` | | זיקה למגזרים: `secular`, `traditional`, `religious`, `haredi`, `arab`, `olim` |
| `parties[].members` | | שמות לפי סדר הרשימה (השאר נוצרים אוטומטית) |
| `parties[].surplusPartner` | | מזהה מפלגה להסכם עודפים |
