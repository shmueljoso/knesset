# כנסת אמיתית, תרחישים ועורך

המשחק מגיע עם עולם בדיוני ועם שלושה תרחישים אמיתיים מוכנים. אפשר גם לבנות הרכב כנסת משלך – בטלפון, בלי לגעת בקוד.

## 1. לשחק בתרחיש מוכן
**משחק חדש** → עוברים את השלבים → בשלב **"באיזו מפלגה?"** בוחרים בכרטיס **"איזו כנסת?"**:

| תרחיש | קובץ | מה יש בו |
|---|---|---|
| 🗳️ לקראת הבחירות לכנסת ה-26 | `elections-2026.json` | הכנסת היוצאת (התפזרה ביולי 2026), נתניהו בראש ממשלה רעועה, ש"ס ויהדות התורה מחוץ לממשלה. בחירות ב-27.10.2026 – בעוד 3 שבועות. הסקרים מסקר חדשות 12 מ-23.9.2026: ישר! 23, ליכוד 20, ביחד 13 ועוד. 💡 בתרחיש "לקראת הבחירות" כדאי לבחור **"ח"כ טרי"** – הרשימות כבר נסגרו, וח"כ מכהן רץ אוטומטית ברשימה שלו.

💡 רוצה לאחד מפלגות או להקים מפלגה לפני הבחירות? סמן/י **"להתחיל 4 חודשים קודם"** בכרטיס התרחיש: אותם נתונים, אבל הרשימות פתוחות (מה-אם).

🌪️ **רמת דרמה** (באותו מסך, ואפשר לשנות גם בתפריט): רגוע / רגיל / פרוע – כמה טלטלות יהיו: מפלגות חדשות של גנרלים וסלבס, מלחמות, משברים, כתבי אישום, פילוגים ואיחודים.

> הנתונים נאספו ממקורות ציבוריים (ועדת הבחירות, סקרי חדשות 12, דיווחים בתקשורת). סדר השמות ברשימות אחרי המקומות הראשונים – משוער. העמדות של המפלגות על 4 הצירים – הערכה משחקית. התכונות, היחסים והאירועים במשחק בדיוניים.

## 2. לבנות כנסת בעורך (בטלפון)
1. במסך הפתיחה: **"🛠️ עורך כנסת"** (או במשחק חדש → "איזו כנסת?" → "🛠️ עורך").
2. אפשר להתחיל מדף חדש, או **"להתחיל מ:"** אחד התרחישים ולשנות אותו.
3. בכל מפלגה: שם, צבע, מושבים (+/−), סקרים באחוזים, 4 סליידרים לעמדות, "בקואליציה", "פריימריז", ורשימת שמות – שם בכל שורה (הראשון = יו"ר).
4. למעלה רואים בזמן אמת: סכום המושבים (חייב להיות 120), כמה יש לקואליציה (צריך 61), ושגיאות אם יש.
5. **"🏛️ לשחק עם הכנסת הזו"** – ממשיכים ליצירת הדמות עם ההרכב שבנית.
6. **"💾 הורדת JSON"** – שומרים את הקובץ כדי לשתף או לערוך במחשב. **"📂 טעינת קובץ"** – פותחים קובץ לעריכה.

הטיוטה נשמרת אוטומטית בדפדפן.

**ייצוא מתוך משחק:** בתפריט (הקשה על התמונה שלך) → "🛠️ ייצוא הכנסת הנוכחית לעורך" – לוקח את מצב הכנסת ברגע זה (מושבים, סקרים, קואליציה, מצב המדינה) ופותח אותו בעורך.

## 3. לעדכן את "לקראת הבחירות" לפי סקר חדש
פתחו את התרחיש בעורך ("להתחיל מ: לקראת הבחירות"), עדכנו לכל מפלגה את **סקרים (%)** (מנדטים בסקר ÷ 1.2 ≈ אחוזים), ושנו את **"בחירות בעוד"** לפי התאריך. אפשר להוסיף מפלגה חדשה עם 0 מושבים ואחוז בסקרים – היא תתמודד בבחירות.

## 3א. כללים ואירועים משלך
בעורך יש שני חלקים חדשים:
- **⚙️ כללים** – אחוז חסימה, ובחירה ישירה לראשות הממשלה.
- **📜 אירועים משלך** – כותבים כותרת, תיאור ועד 4 בחירות; לכל בחירה מספרים (−50 עד 50) למוכרות, מוניטין, מעמד במפלגה, כסף, הון פוליטי ותדמית. האירועים יופיעו במשחק מדי פעם.

בקובץ: `"rules": { "threshold": 2, "directPM": true }`, `"transforms": ["presidential"]` (שינויי משטר שכבר בתוקף), ו-`"events": [{ "title": "...", "body": "...", "choices": [{ "label": "...", "fame": 2 }] }]`.

## 4. מבנה הקובץ (לעריכה ידנית)
ראו `TEMPLATE.real-knesset.json` ואת שלושת התרחישים.

| שדה | חובה | הסבר |
|---|---|---|
| `name` | ✔ | שם ההרכב |
| `description`, `source`, `asOf` | | תיאור, מקור הנתונים ותאריך – מוצגים במסך הבחירה |
| `realPeople` | | `true` אם השמות אמיתיים |
| `knesset` | | מספר הכנסת |
| `startDate` | | תאריך תחילת המשחק `YYYY-MM-DD` |
| `electionInWeeks` | | בעוד כמה שבועות הבחירות (1–260) |
| `listsClosed` | | `true` – הרשימות כבר נסגרו |
| `coalition` | | מזהי המפלגות בקואליציה (אחרת – מחושבת אוטומטית) |
| `ministers` | | משרד → שם ח"כ מהקואליציה. משרדים: `defense`, `finance`, `justice`, `foreign`, `interior`, `education`, `economy`, `health`, `housing`, `transport`, `welfare`, `religion` |
| `world` | | מצב המדינה 0–100: `economy`, `affordability`, `housing`, `security`, `trust`, `cohesion` |
| `issues` | | בולטות סוגיות 0–100: `housing`, `cost`, `draft`, `religion`, `judiciary`, `security`, `crime`, `education`, `wages` |
| `parties[].id` | ✔ | מזהה באותיות לטיניות |
| `parties[].name` / `short` | ✔ / | שם מלא ומקוצר |
| `parties[].color` | ✔ | `#RRGGBB` |
| `parties[].ideology` | ✔ | `econ` (−רווחה/+שוק), `security` (−יוני/+ניצי), `religion` (−חילוני/+דתי), `judiciary` (−בית משפט חזק/+ריבונות הכנסת), בין −100 ל-100 |
| `parties[].seats` | ✔ | מושבים בכנסת; הסכום חייב להיות 120 (0 = לא בכנסת אבל מתמודדת) |
| `parties[].polls` | | אחוז בסקרים (אחרת – לפי המושבים) |
| `parties[].primaries` | | `true` = פריימריז |
| `parties[].sectors` | | זיקה למגזרים: `secular`, `traditional`, `religious`, `haredi`, `arab`, `olim` |
| `parties[].members` | | שמות לפי סדר הרשימה; השאר נוצרים אוטומטית |
| `parties[].satisfaction` | | שביעות רצון פותחת בקואליציה (0–100) |
| `parties[].surplusPartner` | | מזהה מפלגה להסכם עודפים |
| `parties[].blurb` | | משפט תיאור |
