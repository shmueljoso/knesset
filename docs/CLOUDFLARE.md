# המשכן ב-Cloudflare – האתר, החשבונות, השמירות וטבלת השיאים

הכול יושב אצלך ב-Cloudflare, בלי שירותים חיצוניים:

```
          ┌────────────── Cloudflare ──────────────┐
דפדפן ──▶ │ Worker "hamishkan"                      │
APK   ──▶ │   /           → האתר (התיקייה dist/)    │
          │   /api/...    → worker/index.ts         │
          │                   │                     │
          │                   ▼                     │
          │               D1 (SQLite): משתמשים,     │
          │               שמירות בענן, שיאים        │
          └─────────────────────────────────────────┘
```

**המשחק עובד מלא גם בלי השרת:** משחק, שמירות וגיבויים במכשיר, אתגר השבוע והשיאים שלך. השרת מוסיף:

- **חשבון:** אימייל וסיסמה, או אורח/ת שאפשר לשדרג אחר כך.
- **שמירות בענן:** עד 12, עוברות בין טלפון, טאבלט ומחשב.
- **טבלת שיאים:** כללית, אתגר השבוע, הכי מהר לראשות הממשלה, ושלי.
- **מחיקת חשבון:** כל הנתונים נמחקים.
- **קישורי שיתוף:** כנסת מהעורך נשמרת בטבלה `shares`, ומקבלים קישור קצר (`/#s=קוד`). מי שפותח אותו משחק בה מיד, באתר או באפליקציה.

## הקמה – פעם אחת, הכול בממשק של Cloudflare (בלי פקודות)

1. **מסד הנתונים:** כבר נוצר (D1 בשם `hamishkan`), וה-ID שלו כבר כתוב ב-`wrangler.jsonc`.
   את הטבלאות לא צריך ליצור: ה-Worker יוצר אותן לבד בבקשה הראשונה (`worker/schema.ts`).
2. **חיבור הריפו:** ב-Cloudflare נכנסים ל-**Workers & Pages ← Create application ← Import a repository**, ומחברים את GitHub. אחר כך:
   - **Repository:** בוחרים את `shmueljoso/knesset`.
   - **Project name:** `knesset`. חייב להיות זהה לשם ב-`wrangler.jsonc`.
   - **Production branch:** `ccr-b895278b-7u0siq`.
   - **Build command:** `npm run build`
   - **Deploy command:** `npx wrangler deploy`
   - לוחצים **Deploy**. החיבור למסד הנתונים מגיע לבד מ-`wrangler.jsonc`.
3. **הכתובת:** בסוף מופיעה כתובת כמו `https://knesset.<השם-שלך>.workers.dev`. זה האתר, עם חשבונות, שיאים וקישורי שיתוף.
   מעכשיו כל push לענף מעדכן את האתר לבד.
   אפשר לחבר דומיין משלך: **Workers & Pages ← hamishkan ← Settings ← Domains & Routes**.

### לחבר את האפליקציה (APK)

יש שתי דרכים, ואפשר גם את שתיהן:

- **כבר מוגדר:** האפליקציה פונה כברירת מחדל ל-`https://knesset.s029995083.workers.dev` (`DEFAULT_SERVER` ב-`src/online/index.ts`).
- **כתובת אחרת, בלי לבנות מחדש:** באפליקציה נכנסים ל-⚙️ (במסך הפתיחה) ← **שרת**, מדביקים את הכתובת ולוחצים "שמירה".
- **לכל ה-APK-ים הבאים:** בגיטהאב נכנסים ל-**Settings ← Secrets and variables ← Actions ← Variables ← New repository variable**.
  - **Name:** `API_URL`
  - **Value:** הכתובת מסעיף 3.

בלי כתובת, האפליקציה עובדת מלא, רק בלי החלק המקוון.

## הניקוד המנורמל (0–1000)

הניקוד בנוי כך שקריירות שונות יהיו ברות השוואה. הקוד ב-`src/engine/systems/score.ts`.

| רכיב | משקל | איך מחושב |
| --- | --- | --- |
| פסגה | 35% | התפקיד הגבוה ביותר: ח"כ 38 ← יו"ר ועדה 48 ← שר/ה 60 ← יו"ר מפלגה 68 ← ראש ממשלה 85 ← נשיא/ה 92. יש בונוס על איכות התפקיד |
| השפעה | 25% | חוקים ביחס לזמן: הציפייה היא כ-1.2 חוקים לשנה. חוק יסוד שווה 1.5 חוקים ומהפכה 3 |
| המדינה | 20% | השינוי במצב המדינה מאז שהתחלת |
| ציבור | 20% | מוכרות, מוניטין ותדמית |

**מכפילים:**

- **מתחילים מהשטח:** ‎+8%.
- **רמת דרמה:** פרועה ‎+5%, רגועה ‎-5%.
- **פחות משנה במשחק:** הניקוד מוקטן.
- **הרשעה:** ×0.5.

משחק שנעשה בו שימוש בכלים המתקדמים לא נכנס לטבלה הכללית.

> **הגבלה:** הניקוד מחושב באפליקציה, והשרת רק בודק טווחים. בין חברים זה מספיק.

## אבטחה בקצרה

- **סיסמאות:** נשמרות כ-PBKDF2 (100 אלף סבבים) עם salt. הסיסמה עצמה אף פעם לא נשמרת.
- **התחברות:** בטוקן אקראי ששמור במכשיר. בשרת נשמר רק ה-hash שלו, והוא תקף 180 יום.
- **הרשאות:** כל משתמש/ת רואה ומשנה רק את השמירות והשיאים שלו/ה. טבלת השיאים ושמות התצוגה ציבוריים.
- **איפוס סיסמה:** אין כרגע, כי אין שירות אימייל. אורח/ת שרוצה לשמור את החשבון מוסיף/ה אימייל וסיסמה במסך החשבון.
