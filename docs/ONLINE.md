# המשכן אונליין – חשבונות, ענן וטבלת שיאים

המשחק עובד **מלא בלי אינטרנט**: משחק, שמירות, גיבויים, אתגר השבוע והשיאים שלך במכשיר.
החיבור לשרת מוסיף:

| פיצ'ר | מה זה נותן |
| --- | --- |
| 👤 חשבון (אימייל + סיסמה, או אורח/ת) | זהות קבועה ושם בטבלה |
| ☁️ שמירות בענן | עד 12 שמירות. המשחק הנוכחי עולה אוטומטית ועובר בין טלפון, טאבלט ומחשב ("המשך מהענן" במסך הפתיחה) |
| 🏆 טבלת שיאים | כללית, אתגר השבוע, הכי מהר לראשות הממשלה, והשיאים שלי |
| 🎯 אתגר השבוע | כולם מקבלים את אותו עולם (אותו seed) – השוואה הוגנת |
| 📴 עבודה בלי חיבור | מה שלא נשלח נכנס לתור ונשלח כשהחיבור חוזר |
| 🗑️ מחיקת חשבון | מתוך האפליקציה, כולל כל הנתונים בשרת (נדרש בחנות של גוגל) |

## הניקוד המנורמל (0–1000)

הניקוד בנוי כך שקריירות שונות יהיו ברות השוואה. הקוד ב-`src/engine/systems/score.ts`.

| רכיב | משקל | איך מחושב |
| --- | --- | --- |
| פסגה | 35% | התפקיד הגבוה ביותר: ח"כ 38 ← יו"ר ועדה 48 ← שר/ה 60 ← יו"ר מפלגה 68 ← ראש ממשלה 85 ← נשיא/ה 92. מקבלים בונוס על איכות התפקיד: משך הכהונה כראש ממשלה, ואחדות ממוצעת בנשיאות |
| השפעה | 25% | חוקים (חוק יסוד ×1.5, מהפכה ×3, שותפות ×0.3, יוזמה נשיאותית ×0.8), **ביחס לזמן**: הציפייה היא כ-1.2 חוקים לשנה, ולכן קריירה ארוכה צריכה יותר |
| המדינה | 20% | השינוי במצב המדינה מאז שהתחלת (‎-15 עד ‎+15 ממוצע) |
| ציבור | 20% | ממוצע של מוכרות, מוניטין ותדמית |

**מכפילים:**

- **מתחילים מהשטח:** ‎+8%.
- **רמת דרמה:** פרועה ‎+5%, רגועה ‎-5%.
- **שינוי חברתי חזק:** ‎+3%.
- **פחות משנה במשחק:** הניקוד מוקטן.
- **הרשעה:** ×0.5.
- **הדחה מהנשיאות:** ×0.7.

משחק שנעשה בו שימוש ב**כלים המתקדמים** (דילוג או עריכה) מסומן, ולא מופיע בטבלאות הכלליות.

> **הגבלה:** הניקוד מחושב באפליקציה. השרת בודק רק שהמספרים בטווח (0–1000), ומי שמתעקש יכול לזייף. לטבלה בין חברים זה מספיק; לתחרות רצינית צריך הרצה של הסימולציה בשרת.

## הקמת השרת (פעם אחת, כ-10 דקות, חינם)

1. **פרויקט:** נרשמים ל-[supabase.com](https://supabase.com) ← **New project**. בוחרים שם (למשל `hamishkan`), סיסמה למסד הנתונים ואזור (Frankfurt קרוב לישראל).
2. **מסד הנתונים:** נכנסים ל-**SQL Editor** ← **New query**, מדביקים את כל הקובץ [`supabase/schema.sql`](../supabase/schema.sql) ולוחצים **Run**.
   - הסקריפט יוצר את הטבלאות, את ההרשאות לכל שורה (RLS) ואת פונקציית מחיקת החשבון.
   - אפשר להריץ אותו שוב בבטחה.
3. **התחברות:** ב-**Authentication ← Sign In / Providers**:
   - **Email**: מופעל. מכבים את **Confirm email** אם רוצים שההרשמה תעבוד מיד, בלי אימייל אישור.
   - **Allow anonymous sign-ins**: מפעילים, אם רוצים כפתור "המשך כאורח/ת".
4. **המפתחות:** ב-**Project Settings ← API** מעתיקים את **Project URL** ואת **anon public key**.
   - ה-anon key נועד להיות ציבורי. מה שמגן על הנתונים הוא ההרשאות שבסקריפט, לא הסתרת המפתח.
   - **לעולם** לא שמים באפליקציה את ה-`service_role` key.
5. **במחשב:** מעתיקים את `.env.example` ל-`.env.local` וממלאים את שני הערכים. אחר כך `npm run dev`, או `npm run android:sync` לאפליקציה.
6. **ב-GitHub:** כדי שה-APK והאתר ייבנו עם השרת, נכנסים ל-**Settings ← Secrets and variables ← Actions ← New repository secret** ומוסיפים:
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`

### אתר (לא חובה)

כדי לשחק גם מדפדפן בכתובת קבועה:

1. **הפעלה:** ב-**Settings ← Pages ← Source** בוחרים **GitHub Actions**.
2. **פרסום:** ב-**Actions ← Web (GitHub Pages) ← Run workflow**.
3. **פרסום אוטומטי:** כדי לפרסם אוטומטית בכל push, מוסיפים משתנה (Variables) `PAGES_ENABLED=true`.

הכתובת תהיה `https://shmueljoso.github.io/knesset/`. אם הריפו פרטי, Pages דורש מנוי GitHub בתשלום.

## לנסות בלי שרת

בכלי המפתחים של הדפדפן (או ב-`chrome://inspect` באנדרואיד), מריצים:

```js
localStorage.setItem('hamishkan.onlineMock', '1'); location.reload();
```

זה מפעיל שרת מדומה שנשמר במכשיר (`src/online/mock.ts`), עם אותו ממשק בדיוק. לביטול: `localStorage.removeItem('hamishkan.onlineMock')`.
