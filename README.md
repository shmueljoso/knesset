# המשכן – סימולטור קריירה פוליטית בכנסת

משחק סימולציה למובייל (PWA) שבו מטפסים מעוזר/ת פרלמנטרי/ת ועד ראשות הממשלה: ועדות, חקיקה בשלוש קריאות, יחסים וחובות עם חברי כנסת, מעבר והקמת מפלגות, בחירות לפי שיטת בדר-עופר והקמת קואליציה.

כל המפלגות והדמויות בדיוניות; התהליכים מבוססים על הכללים האמיתיים (45 יום הנחה, ועדת שרים לחקיקה, אחוז חסימה 3.25%, הסכמי עודפים, חוק ה"פורש" ופילוג בשליש, פיזור אם התקציב לא עובר).

מסמך העיצוב המלא: [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md).

## הרצה

```bash
npm install
npm run dev        # שרת פיתוח (פתחו בטלפון דרך כתובת הרשת)
npm test           # בדיקות מנוע + סימולציה של 5 שנים
npm run build      # בנייה ל-dist/ כולל service worker
npm run e2e        # בדיקות דפדפן במבט iPhone (CHROMIUM_PATH=... אם צריך)
```

## מבנה

- `src/engine/` – מנוע המשחק: TypeScript טהור, דטרמיניסטי (RNG עם seed בתוך המצב), ללא תלות ב-UI.
  - `systems/` – יחסים, דעת קהל, חקיקה, הצבעות, בחירות, מפלגות, ממשלה, צוות, אירועים.
  - `data/` – תוכן: מפלגות, תבניות חוק, אירועים, רקעים, מיקומים.
  - `ops.ts` – אפקטים דקלרטיביים; כך כל בחירה מציגה "השפעה צפויה" לפני שבוחרים.
- `src/ui/` – React: מפה איזומטרית ב-SVG (גרירה וצביטה), דאשבורד, אנשים, חקיקה, חדשות.
- `tests/` – Vitest. `e2e/` – Playwright.

## שלב 1 – Vertical slice

- שני תרחישים: "מהשטח" (שנה לפני בחירות) ו"ח"כ טרי".
- 11 מפלגות בדיוניות, ~250 דמויות עם תכונות נסתרות, רשת חברים ופנקס חובות.
- מסלול חקיקה מלא, ספירת קולות ושכנוע מתלבטים, מיני-משחק דיון בוועדה.
- פריימריז/שריון, בחירות, הקמת ממשלה אוטומטית (או הצעה להצטרף אם הקמת מפלגה).
- מעבר מפלגות עם קנס מוניטין, פילוג חוקי, פרישה ("פורש"), הקמת מפלגה וגיוס לרשימה.
- כ-30 כרטיסי אירוע, פיד חדשות, דו"ח שבועי ומצב המדינה שמושפע מחוקים.

## שלב 2 – קואליציה וממשלה

- **משא ומתן קואליציוני:** יו"ר המפלגה הגדולה בגוש מקבל מנדט ל-28 יום (+14). מחלקים תיקים, ראשויות ועדות, כספים קואליציוניים, סעיפי חקיקה ווטו. יש התנגשויות (אותו תיק לשתי מפלגות, וטו מול דרישת חקיקה) וקופה מוגבלת. כמפלגה שותפה – מתמקחים, וכוח המיקוח תלוי בכמה צריכים אותך.
- **תחזוקת קואליציה:** לכל שותפה שביעות רצון; משברים פתאומיים, סעיפי הסכם שלא קוימו, וטו שהופר. שותפה מתוסכלת פורשת → ממשלת מיעוט → אי-אמון קונסטרוקטיבי (61 לממשלה חלופית) או פיזור.
- **שר/ה:** תיק מיו"ר המפלגה, בשיבוץ מחדש או במשא ומתן. תכניות דגל בכל משרד (12 משרדים), מינוי מנכ"ל (נאמן / מקצועי / מקורב), תקציב שמתחדש עם חוק התקציב ותוספות מהאוצר, ישיבות ממשלה ומשמעת מול ראש הממשלה – כולל פיטורים.
- **חקיקה ממשלתית:** תזכיר חוק (21 יום) ← ועדת שרים ← ישר לקריאה ראשונה.
- **ראשות המפלגה וראשות הממשלה:** התמודדות על ראשות המפלגה, ומשם – מנדט להרכבת ממשלה.
- **קריית הממשלה נפתחת:** משרד רה"מ, האוצר והמשרד שלך.

הבא בתור (שלב 3): חוקי יסוד ורוב מיוחס, בג"ץ, שערוריות ועדות חקירה, ומצב "כנסת אמיתית".
